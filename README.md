# ⚡ GrabVault — Video & Audio Downloader

**GrabVault** is a modern, responsive, and fast multi-platform video and audio downloader web application. It allows users to download content from popular platforms like YouTube, Instagram, Facebook, TikTok, and Pinterest without any hassle.

![GrabVault Preview](https://via.placeholder.com/800x450.png?text=GrabVault+Web+App) <!-- Add your app screenshot here -->

---

## ✨ Features

- **🌐 Multi-Platform Support**: Works seamlessly with YouTube, Instagram (Reels & Posts), Facebook, TikTok (No Watermark), and Pinterest.
- **🎬 Multiple Formats & Qualities**: Download as MP4 video (from 144p up to 1080p) or extract audio as high-quality MP3.
- **🎨 Interactive UI & Dark Mode**: Beautiful theme toggle (Light/Dark mode) built with clean CSS animations, 3D tilt effects, and smooth reveal dynamics.
- **⚡ Instant Link Processing**: Asynchronous background fetching and streaming direct downloads.
- **📱 Fully Responsive**: Built for all screen sizes — Mobile, Tablet, and Desktop.
- **🔒 Privacy-First**: No user tracking, no mandatory sign-ups, and no stored download logs.

---

## 🛠️ Built With

- **Frontend**: HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid, Custom Keyframes), JavaScript (ES6+)
- **Backend / Integration**: Python (Flask / Node.js integration for fetching & streaming media)
- **Typography**: Space Grotesk, Inter, JetBrains Mono
